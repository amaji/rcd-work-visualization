# RCD-WORK-VISUALIZATION

- The readthedocs URL for this website is: https://rcdworkviz.readthedocs.io/en/latest/index.html
- The document source files (RST, Markdown, etc.) are in the folder `source`.
- We recommend creating a separate RST file for each section under `sections/` and then adding it in `source/index.rst`
- If you notice any errors with the readthedocs pages, please submit an [issue](https://github.com/amaji/rcd-work-visualization/issues).

We welcome contributions from the community to expand this guide and share case studies. If you have an idea, please reach out to us or create a pull request.
