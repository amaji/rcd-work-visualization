**Module 2: Break Work Down**
=============================

.. _purpose-2:

**Purpose**
-----------

Make work easier to track, prioritize, and finish.

RCD teams often work with tasks that are either too vague (“fix access
issues”) or too granular (“email researcher”). Right‑sizing work exposes
**dependencies**, reduces overwhelm, and makes progress visible. This
module helps teams shape work into clear, actionable units that move
smoothly across the board.

**Why Right‑Sizing Work Matters**
---------------------------------

- Reveals hidden **dependencies**

- Reduces cognitive load

- Makes priorities clearer

- Prevents “stuck” cards

- Improves flow across the team

- Helps avoid the Time Thief of **Neglected Work**

**Examples of Well‑Sized Work Items**

**Too Vague → Right‑Sized**

- “Fix access issues”

  - Confirm required access level

  - Update storage ACLs

  - Validate access via Globus

- “Set up project space”

  - Provision storage allocation

  - Create Globus endpoint

  - Configure Slurm account

- “Improve onboarding”

  - Draft onboarding checklist

  - Update Globus instructions

  - Add Slurm quick‑start guide

Right‑sized work is clear, actionable, and finishable within a few days.

**Breakdown Checklist**
-----------------------

Use this quick checklist to shape any work item:

- **Clear Outcome**: You can describe what “done” looks like.

- **Single Owner**: One person can move it forward.

- **Actionable**: Starts with a verb.

- **Short Duration**: Finishable in a few days.

- **Visible Dependencies**: External teams or systems are explicit.

- **No Hidden Steps**: Avoids “and then…” work.

If an item fails any check, break it down.

**Quick Exercise: Refine an Oversized Card**
--------------------------------------------

A 5‑minute team activity:

1. **Pick one oversized card** (e.g., “Set up project space”).

2. Ask: **“What are the first two things someone actually does?”**

3. Turn those into separate actionable steps.

4. Ask: **“What needs to be validated or tested?”**

5. Capture that as its own step.

6. Ask: **“Is anything dependent on another team or system?”**

7. Add those dependencies explicitly.

8. Replace the oversized card with the new right‑sized items.

This exercise quickly exposes hidden work and clarifies flow.

.. _start-small-1:

**Start Small**

Pick **three large tasks** from your current work and break each into a
few actionable steps.

This builds confidence and immediately improves flow.
